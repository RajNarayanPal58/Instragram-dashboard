# Instagram Global Influencers

1.Short Description

   Dashboard provides insights into global Instagram influencers, their followers, categories, channels, engagement rates, and influence scores.
The goal is to understand influencer performance and identify patterns across different countries and content categories.

2.Project Objectives

   Compare the number of followers across different channels and categories. Analyze and compare the total followers of each category. Evaluate the engagement rate and influence score of different channels.Analyze the application’s usage across different countries and identify the areas with the highest concentration of users. Highlight the total number of posts shared by the top-performing channels. Present all these insights through a creative and interactive dashboard.

3. Tech Stack

    The dashboard was built using the following tools and technologies:
• 📊 Power BI Desktop – Main data visualization platform used for report creation.
• 📂 Power Query – Data transformation and cleaning layer for reshaping and preparing the data.
• 🧠 DAX (Data Analysis Expressions) – Used for calculated measures, dynamic visuals, and conditional logic.
• 📁 File Format – .pbix for development and .png for dashboard previews.
